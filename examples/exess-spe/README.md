# EXESS Single Point Energy Example

Demonstrates how to run a single-point energy (SPE) calculation using rush-py and visualize the results.

## Quick Start

```bash
export RUSH_TOKEN="your-token"
export RUSH_PROJECT="your-project"

python 02_exess_spe.py
```

## What This Example Covers

1. Running an EXESS energy calculation with `exess_energy`
2. Extracting and printing total energy from the output

## Input Data

- `water_topology.json` — Water molecule (H₂O) in TRC topology format
