Prepare¶

Structure preparation module for the Rush Python client.

Usage:

from rush import prepare

# Protein only
result = prepare.protein("protein.pdb").fetch()

# Protein-ligand complex
result = prepare.protein_ligand("complex.pdb", ligand_names=["LIG"]).fetch()

Submit a complex preparation job for a PDB or TRC file.

Internally runs prepare-protein, extracts ligands, merges, and uploads the combined TRC. The returned Run wraps the prepare-protein job. Calling .fetch() or .save() blocks until the protein preparation completes, then performs the merge locally.

Returns a Run handle. Call .fetch() to get the parsed TRC, or .save() to write the output files to disk.

Parameters:
