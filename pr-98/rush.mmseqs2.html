MMseqs2¶

MMseqs2 module for the Rush Python client.

MMseqs2 generates multiple-sequence alignments (MSAs) from amino acid sequences.

Usage:

from rush import mmseqs2

paths = mmseqs2.search(["MKFLILLFNILCL..."]).save()
