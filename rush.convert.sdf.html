rush.convert.sdf¶

Python implementation of from_sdf functionality.

Converts SDF (Structure Data File) format to TRC (Topology-Residues-Chains) JSON format. Supports SDF V2000 format.

Convert a parsed molecule to TRC format.

Creates a TRC with: - Single residue containing all atoms - Residue name from molecule name (or “LIG” if empty) - Single chain containing that residue - Bonds as connectivity - Charges as formal_charges

rush.convert.sdf.parse_sdf_entry(content)[source]¶

Parse a single SDF entry into a molecule dictionary.

SDF V2000 format: - Line 1: Molecule name - Line 2: User/Program name - Line 3: Comment - Line 4: Counts line (num_atoms num_bonds …) - Lines 5-4+num_atoms: Atom block (x y z symbol …) - Lines 5+num_atoms-4+num_atoms+num_bonds: Bond block - Properties block (optional, e.g., CHG for charges) - Data items (optional, e.g., SMILES) - Terminator: “$$$$”

Parameters:

content (str)

Return type:

Dict[str, Any]
